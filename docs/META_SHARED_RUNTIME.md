# Shared Meta runtime and restored capacity

The opt-in `--meta-shared-runtime` profile fixes the confirmed Meta residency
regression. The current parent retains478192 bytes,832 fewer than the unchanged
479024-byte control and5424 fewer than the preceding483616-byte frontend.
It passes the ordinary DOS8086 six-stream/nested-child workload while editing
and exercising a Meta key before and after ASPECT reuses the arena. This is a
source checkpoint; no deployment or full application-parity claim is made.

## Layout and lifetime

Line/Port, the command reference and Meta now use one resident loader. The
standalone Meta loader remains available for its independent diagnostic/profile;
it is not linked alongside the shared loader. The Meta frontend and reference
painting/navigation live in PCMETA.OVL. Only the reference key classifier stays
resident. It is generated from the same39-item C table and exact feature-selected
action/normalization methods, so there is no second hand-maintained key map.

The persistent reference selection/refusal/frame pointer stays in the parent's
existing near data. Transient code and code-based frontend state reload from the
matched file. DGROUP remains65520 bytes; the8192-byte stack,63000-byte history,
snapshot and receive/frame capacities are unchanged. PCMETA contains26916 code
bytes and37 declared relocation words, in the existing arena at offset16384.
The shared format admits at most43000 code bytes/512 fixups below the protected
saved image. The older independent loader keeps its24000-byte bound.

Module identity, exact EOF, CRC before fixups, ordered nonoverlapping fixups,
PSP/data-base identity, physical bounds and explicit arena admission remain
checked. Read/CRC steps handle at most512 bytes; fixup turns handle at most32
words. The Meta file owner must retire before the arena can be reused. Before
publication, a closed editor compares the frozen runtime table/selector and
checks its pure owner predicate. No DOS/foreground callback intervenes through
publication and the resident retirement check. Fatal/ambiguous ownership keeps
the code and callback arena held until DOS exit.

The reference retires before opening Meta, Line/Port, the browser or other tools.
Its Help path suspends without retaining callable bank code, queues the existing
PROGRAM helper, and reloads afterward with persistent selection preserved.
Suspension permits no bank entry. Direct script/info prompts prepare selection
without loading unused code; returning to the reference loads it on demand.
Escape, shutdown and the call-log transition also retire the reference lease.

Enhanced BIOS navigation (`AL=E0` with a scan code) is normalized at both Meta
frontends. Literal CP437 E0 remains text. A real Up-key test exposed this gap:
without normalization, revising the intended last key modified the first one.

## Evidence

[The receipt](validation/meta-shared-runtime.json) binds exact product hashes,
public inputs and these independent gates:

- Ordinary DOS8086:32 checks, six buffered streams across three DOS children,
  missing-file recovery, VT220/ANSI reset, exact files/hardware restoration.
  Actual Alt-0 output changes from META1 to META2 around the scripts, proving
  accepted row navigation/adoption and successful bank reload after arena reuse.
- Twelve Meta cases: edit/save/load, direct/reference/browser entry, reopen,
  early Escape/reopen, missing module, reference Escape/context-help return,
  script prompt and Program Info return. Four additional Alt-P cases repeat in
  the cold source export; direct reference/browser Alt-P routes also pass.
- Two native global-Help round trips restore the complete reference frame and
  resume UART/parser input. The39-command reference/refusal/browser/help probe
  passes separately with actual ROM-font/frame captures.
- Eight malformed-module cases: each of Line/Port and Meta refuses missing,
  short, changed and trailing files twice, then resumes ordinary terminal input.
  These are file-content faults, not injected DOS close failures.
- A727-file export, with no originals/private files/prior objects/ancestor Git,
  reproduces the parent and both overlays exactly, then repeats three Meta and
  four Alt-P DOS cases. The disabled source build remains exact `ff6bb369…`.
- Actual stock Enigma and Synchronet Meta/editor round trips preserve all4000
  frame bytes/cursor/shape. Independent delivered-prefix replay matches all1920
  logical cells/attributes on each BBS with zero differences. Each has nine
  damaged-copy refusals and one unchanged-copy control. SynthModem proxy framing
  is250ms and input pacing20ms; observed Synchronet uses386/UMB for its passive
  observer. Its unobserved8086 core workflow is a separate gate.

Earlier shared-loader prototypes still exceeded the capacity budget; moving only
Meta's frontend was insufficient. The reference move funds the complete workload.
The first Help-reload test also caught a transient loading notice in the saved
frame; resumed reference loads now preserve the old frame until verified code
can redraw it. Failed attempts are not accepted evidence.
