# Enigma reliability, then original daily-use commands

The agreed order is reliable Enigma operation first, followed by the original
menus and daily-use functions. Full Host, other terminal emulations and legacy
protocol parity remain later work; 39 visible command labels are not 39 working
commands. See FEATURES.md for the complete acceptance gates.

## Current release discipline

The selected connection package and its remote hashes are recorded privately in
build/connection-test-current.json. Never infer installation or activation from
successful packaging. Keep application hashes, source proof, automated evidence,
actual remote read-back and user-operated physical observations distinct.
Preserve PRM/DIR/KEY/KBD/XLT and the FON call log in every update.

## Reliability acceptance

- Main menu: exact CP437/color cells, classic ANSI and coherent80x24 with status.
- Editor: arrows, Home/End, Insert/Delete, backspace and multiline page movement.
- Modal actions: Alt-Z/setup/script return preserves display, input and ownership.
- Pressure: sustained output, flow-control stalls and bounded buffering.
- Reconnect: local hangup, remote close and three calls in one parent process.
- Transfers: binary upload/download hashes, cancellation/retry and carrier loss.

Existing receipts remain historical evidence for their exact product. New build
checks must identify their executable and repeat affected cases. Synthetic BBS
accounts and unsaved drafts are used for automated sessions. The live BBS,
SynthModem and ATA are not restarted merely to run local regression tests.

The user has confirmed successful real connections and improved compatibility.
The Enigma classic-menu fix was activated on November2; physical screen
confirmation after that restart is pending. Complete physical acceptance is
still open and must not be represented as either wholly untested or complete.

## Following command integration

After reliability acceptance, connect recovered terminal controls first, then
file/DOS actions, directory/key tools and Chat/UI polish. Trace each original
contract, reuse the existing component, verify serial/display/child lifetimes,
add a DOS regression, then enable its reference entry. Preserve explicit refusal
for Host/Kermit and every other command whose real action remains incomplete.
